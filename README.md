# Expense Tracker System

## About the Project

Expense Tracker System is a web-based application developed to help users
manage and track their daily income and expenses.

The project provides a simple and user-friendly interface for recording
transactions and keeping track of financial activities.

## Features

- Add income and expense transactions
- View transaction records
- Track total income and expenses
- Monitor current balance
- Simple and user-friendly interface
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
